# Esmeralda - Portfolio Website

A single-page personal portfolio website built with plain HTML, CSS, and JavaScript.

## Live Demo
Link coming soon after GitHub Pages deployment.

## Features
- Navigation bar with anchor links
- About section with personal bio
- Testimonials rendered from a JavaScript object using a loop
- Projects rendered from a JavaScript array using a loop
- Contact section with email and GitHub
- Responsive layout

## Files
- index.html
- style.css
- script.js
- README.md

## Tech Used
HTML, CSS, JavaScript (no frameworks)
