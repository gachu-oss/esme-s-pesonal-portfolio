# Alex Rivera — Portfolio Website

> A clean, responsive personal portfolio built with plain HTML, CSS, and JavaScript.

**🔗 Live Demo:** [alexrivera.github.io/portfolio](#) *(update after deploying to GitHub Pages)*

---

## ✨ Features

- **Responsive design** — looks great on mobile, tablet, and desktop
- **Smooth scroll & animations** — fade-up reveals using Intersection Observer
- **Testimonials rendered via JavaScript** — stored in an object, looped onto the page (no hard-coded HTML)
- **Projects rendered via JavaScript** — dynamic project cards with tech tags
- **Accessible** — semantic HTML5, ARIA labels, keyboard-navigable nav
- **No frameworks** — 100% vanilla HTML, CSS, and JavaScript

---

## 📁 File Structure

```
portfolio/
├── index.html   # Page structure & semantic markup
├── style.css    # All styles (design tokens, layout, animations)
├── script.js    # Data objects + render logic + nav + scroll effects
└── README.md    # This file
```

---

## 🚀 Running Locally

No build step needed! Just open `index.html` in your browser, or use a simple dev server:

```bash
# Using VS Code Live Server extension — right-click index.html → "Open with Live Server"
# OR with Python
python -m http.server 5500
```
